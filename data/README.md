# Data

This repository contains a curated XES3G5M collaboration package. Large CSV files are stored with
Git LFS; install Git LFS before cloning or run `git lfs pull` after cloning.

- `raw/xes3g5m`: minimal source files needed to reproduce preprocessing.
- `processed/xes3g5m`: model-ready questions, interactions, and quality reports.

See `DATASET.md` for provenance, licensing, exclusions, and known limitations. Do not add school
data, student names, contact details, or re-identification keys to this repository.
